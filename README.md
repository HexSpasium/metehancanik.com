# Metehan Canik — Dijital Biyografi

Bu site, sağlanan iki sayfalık özgeçmiş ve 20 kişisel fotoğraf temel alınarak hazırlanmış statik bir GitHub Pages sitesidir.

## Yayınlama
1. Bu klasördeki dosyaları GitHub deposunun kök dizinine yükleyin.
2. Repository → Settings → Pages bölümünü açın.
3. Build and deployment altında `Deploy from a branch` seçin.
4. Branch: `main`, Folder: `/ (root)` seçip kaydedin.

Ana sayfa `index.html` dosyasıdır. Harici JavaScript kütüphanesi kullanılmaz. Google Fonts bağlantısı dışında site dosyaları yereldir.

## Not
İş deneyimlerinin tarihleri CV'de bulunmadığı için kronolojik tarih eklenmemiştir. Fotoğraflar 20 adet olarak arşive alınmıştır. Telefon numarası ve PDF CV, kişisel verileri gereksiz yere herkese açık etmemek için siteye ayrıca eklenmemiştir.
